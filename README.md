## 🧱 How I Build (Production-Ready Checklist)

```text
✅ Typed contracts          →  TypeScript across components, API layers and state
✅ Resilient UI             →  loading, empty, error and retry states for every async flow
✅ Real-time safe           →  reconnection, backpressure and cleanup on unmount
✅ Performance budget       →  lazy routes, split bundles, optimized assets
✅ Accessible by default    →  semantic markup, focus management, contrast
✅ Maintainable structure   →  feature folders, small components, single responsibility
```
